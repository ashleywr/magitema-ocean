# Changelog

## 0.1.0 prototype

- Added two selectable expanded-depth ocean Overworld presets.
- Added an original analytic seafloor with shelves, basins, ridges, trenches, and optional sparse islands.
- Added marine surface and underground biomes, protected dry cave density, scoped source-water filling, and explicit structure/resource policies.
- Added a shared, persisted starter platform, renewable kelp, and an original depth-aware buried salvage structure.
- Added oceanblock/exploration resource profiles and NauTec ocean tags and opening recipes.

Runtime verification status is kept in the wrapper's test report; a successful build alone does not establish runtime compatibility.
